# AI Mock Interview Trainer

AI-powered mock interview platform built with the MERN stack. The platform will generate role-specific interview questions, evaluate candidate answers, provide communication feedback, track performance, and create personalized improvement plans.

## Planned stack

- React + Vite
- Node.js + Express
- MongoDB + Mongoose
- Gemini AI
- JWT authentication
- Web Speech API
- Recharts

## Project structure

```text
client/   # React frontend
server/   # Node.js + Express backend
```

## Status

🚧 Initial MERN foundation in progress.
